# WhatsApp Playbook — Janata Masala

Source: NLM Q1–Q3 + Q5 synthesis

## Core flow: list-dump order
1. Customer sends plain-text list in WhatsApp
2. Staff/system parses items, checks inventory
3. Itemized bill sent in chat
4. Payment link (Razorpay) in same thread
5. CRM note + inventory delta logged

## WhatsApp Channels (broadcast)
New arrivals, seasonal products, festival combos — for moms/older demographic who prefer channels over Instagram.

## Interactive patterns (Business API)
- Reply buttons: bulk qty (50kg / 100kg / custom)
- List picker: festival combos, product categories
- Catalog carousel: top SKUs
- Order confirmation + tracking message
- Post-delivery feedback flow

## CRM segments
- Product affinity (kaju buyers get kaju content)
- Life events (birthdays, anniversaries)
- Geo: Ghatkopar belt Gujarati/Kachchi

## Phase mapping
- Phase 1: Manual operator + WhatsApp Business setup
- Phase 2: Inventory-linked order intake
- Phase 3: Agentic CRM + automated flows
