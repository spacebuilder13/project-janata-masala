# Janata Masala — Brand Guidelines

## Brand essence

- **Category:** Indian spices and masala — trusted household name
- **Tone:** Warm, authentic, rooted in tradition, forward-looking on commerce
- **Audience:** Retail customers, distributors, Gujarati-Kachchi communities (Ghatkopar belt), housewives, internal JM team
- **Framing:** Heritage authority — Sabyasachi not Zara. "Janta" as asset: where serious buyers come for originality, not aspiration alone.
- **North star:** Brand as operating system — can JM run without Jay physically present?

## Visual direction (Sandy system, JM accent)

| Token | Usage |
|-------|-------|
| `--color-sandy-bg` | Graph paper canvas |
| `--color-sandy-gold` | Spice warmth — primary accent |
| `--color-sandy-tea` | Secondary — earthy green |
| `--color-jm-spice` | `#C45A1A` — chili / masala accent (JM-specific) |
| `--color-jm-turmeric` | `#E8B84B` — turmeric highlight |

## Typography

- **Display:** DM Serif Display — headlines, adventure titles
- **Body:** Inter — UI copy, cards
- **Mono:** IBM Plex Mono — labels, tags, code

## Motion vocabulary

arrive · breathe · reveal · cinematic

## Background policy

| Surface | Background |
|---------|------------|
| Login | GraphPaper + vignette only |
| Home hub | GraphPaper + vignette (via Layout) |
| Adventure / Explorations | GraphPaper only — no LivingLines on page |
| Cards / modals | Solid surface + shadow — no grid bleed-through |

**LivingLines:** Not used on login, home, or full-page layouts. Optional only inside contained hero banners (e.g. NorthStarBanner) at ≤15% opacity.

## Typography minimums

| Role | Size | Notes |
|------|------|-------|
| Body copy | 14px | line-height 1.55 |
| Secondary | 13px | captions, card descriptions |
| Mono labels | 11px | `.mono-caps` — uppercase labels only |
| Inputs | 14px | sans-serif, no uppercase transform |

## Do / Don't

- **Do:** Use graph paper background with vignette, warm spice accents, authentic WhatsApp frames
- **Don't:** Stack LivingLines on graph paper; generic fintech dark mode; unverified JM revenue claims; production system labels on demos
